# Untouch Flow — iPhone / iPad

Two methods. Pick one.

| | Method 1: Orion | Method 2: Safari + Userscripts |
|---|---|---|
| Download | `method-1-orion/untouch-flow-orion.zip` | `method-2-safari-userscript/untouch-flow-safari-userscript.zip` (or the `.user.js` inside it) |
| What it is | The Firefox extension, same build as `firefox/` | A Safari-only userscript (not the same as the Chrome/Edge/Firefox build) |
| Popup (profiles, settings, 13 languages) | Yes | No, MiniTool only |

## Method 1: Orion (recommended)
1. Download `untouch-flow-orion.zip` to the iPhone (Files / AirDrop). Do not unzip.
2. Orion > Extensions > `+` > **Install from File** > pick the zip.
3. Force-close Orion once, reopen, open a manga page, tap the MiniTool play button.

## Method 2: Safari + Userscripts
1. Install **Userscripts** (App Store). Settings > Safari > Extensions > Userscripts: on, "Always Allow on This Website".
2. Unzip `untouch-flow-safari-userscript.zip` in Files, then move `manga-flow-scroller.user.js` into your Userscripts folder (overwrite the old copy). `@version` must be 2.2.0 or newer.
3. Safari `ᴀA` > Userscripts > script on, refresh the page, tap the MiniTool play button.
